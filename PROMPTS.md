# 📋 Telegram me paste karne ke liye

Pehle ye bhejo (ek baar):

```
/best
```

Phir neeche se koi bhi line copy karke paste kar do.

---

## ⚡ Sabse aasan — bas ye bhejo

| bhejo | milega |
|---|---|
| `/day` | din ka random scene |
| `/night` | raat ka random scene |
| `/monsoon` | baarish ka scene |
| `/food` | khana peena |
| `/daily` | roz ka din |

Har baar **naya scene** aata hai. Apna detail bhi jod sakte ho:

```
/night red saree
```
```
/food with friends
```
```
/daily white kurta
```
